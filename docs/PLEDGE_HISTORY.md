# Pledge History — bsgusa / bala-archives

Dated log of public engagement pledge reviews and changes.

## 2026-10-23 — Pledge established

The public engagement pledge was created with 5 points:

1. Build in public — repos public, roadmaps public, build logs dated and public
2. Tell the truth — no fabricated certifications, customers, funding, or models
3. Respond — issues ≤7 days, PRs ≤14 days, email ≤7 days
4. Collaborate — good-first-issues and PR templates in bala-weave
5. Connect everything — bala-nexus keeps one map of the whole world

No changes yet. Reviewed at creation.

## Review cadence

Each session, the pledge is reviewed. If any point can no longer be kept, it is logged here with a date and reason before being adjusted.

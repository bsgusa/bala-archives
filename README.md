## Public engagement pledge

We pledge to:

1. **Build in public.** Repos are public. Roadmaps are public. Build logs are dated and public.
2. **Tell the truth.** No fabricated certifications, customers, funding, or models. Every compliance item carries an evidence pointer or is honestly marked unknown.
3. **Respond.** Issues acknowledged within 7 days; pull requests reviewed within 14 days.
4. **Collaborate.** Good-first-issues and PR templates live in `bala-weave`. Anyone can propose a connection.
5. **Connect everything.** `bala-nexus` keeps one map of the whole world.

This pledge is reviewed each session and updated in `reports/LOG.md` if it changes.
